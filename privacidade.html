Resumo simples: O 70/30 App não coleta, não armazena e não compartilha nenhum dado pessoal. Seus dados ficam exclusivamente no seu dispositivo e, se habilitado, no seu próprio iCloud.
01
Sobre esta Política

Esta Política de Privacidade descreve como o aplicativo 70/30 — Controle Financeiro ("App"), desenvolvido por Connect – Soluções em TI (CNPJ 20.770.172/0001-51), trata as informações dos seus usuários.

Ao utilizar o App, você concorda com os termos descritos neste documento.

02
Dados que NÃO coletamos

O 70/30 App foi desenvolvido com privacidade como princípio central. Não coletamos:

  • Nome, e-mail ou qualquer informação de identificação pessoal
  • Dados financeiros, bancários ou de cartão de crédito
  • Localização geográfica
  • Dados de uso, telemetria ou analytics
  • Informações do dispositivo

O App não exige criação de conta ou cadastro de qualquer natureza.

O App armazena localmente algumas preferências de uso (aparência, feedback tátil, antecedência de avisos e histórico de notificações). Essas preferências são técnicas, não contêm dados pessoais e ficam apenas no seu dispositivo.

03
Onde seus dados são armazenados

Todos os dados que você insere no App (gastos, renda, cartões, recorrências) são armazenados exclusivamente no seu dispositivo, utilizando o SwiftData com armazenamento local.

Se você estiver logado com uma conta Apple ID e tiver o iCloud habilitado, os dados podem ser copiados automaticamente para o seu iCloud privado. Essa cópia funciona como backup e restauração — útil ao reinstalar o app ou trocar de iPhone. Não há sincronização contínua entre dois dispositivos em uso simultâneo. Os dados no iCloud são gerenciados diretamente pela Apple, sob a Política de Privacidade da Apple, sem qualquer acesso por nossa parte.

Em nenhuma hipótese os dados são enviados para servidores próprios da Connect – Soluções em TI.

04
Compras dentro do App (In-App Purchases)

O App oferece compras opcionais para desbloqueio de funcionalidades premium. Todas as transações são processadas exclusivamente pela Apple através da App Store.

Não temos acesso a dados de pagamento, número de cartão, ou qualquer informação financeira relacionada às compras. Para dúvidas sobre cobranças, consulte diretamente a Apple em reportaproblem.apple.com.

A única informação que o App armazena localmente é o status de desbloqueio premium (se você comprou ou não), sem nenhum dado de transação.

05
Notificações

O App pode solicitar permissão para enviar notificações locais. São dois tipos de alerta: vencimento de contas e faturas, e aviso quando uma categoria atinge 80% do orçamento mensal — antes de você estourar o limite. Essas notificações são geradas e entregues localmente, sem envolvimento de servidores externos.

Você controla as notificações em dois lugares: dentro do próprio app (incluindo a antecedência do aviso de vencimento) e nas configurações do iPhone em Ajustes → 70/30 → Notificações.

06
Compartilhamento com terceiros

Não compartilhamos, vendemos, alugamos ou transferimos quaisquer dados dos usuários para terceiros, pois simplesmente não coletamos esses dados.

O App não integra SDKs de publicidade, ferramentas de rastreamento, ou plataformas de analytics de terceiros.

07
Exclusão dos dados

Como todos os dados ficam no seu dispositivo, você tem controle total sobre eles:

  • Apagar tudo pelo app: Em Ajustes dentro do 70/30, use "Apagar todos os dados" — remove os dados locais e o backup no iCloud de uma vez.
  • Desinstalar o app: Todos os dados locais são removidos automaticamente pelo iOS.
  • Excluir somente o backup no iCloud: Acesse Ajustes → [seu nome] → iCloud → Salvos no iCloud → Ver tudo → 70/30 App → Excluir.
08
Menores de idade

O App é classificado como livre para todas as idades (4+) na App Store. Como não coletamos nenhum dado pessoal, não há tratamento de dados de menores de qualquer natureza.

09
Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. Quando houver alterações relevantes, atualizaremos a data de "última atualização" no topo do documento e, quando aplicável, notificaremos os usuários através do App.

O uso continuado do App após as alterações constitui aceitação da nova política.
